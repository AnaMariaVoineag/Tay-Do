### 🎤 Tay-Do List App
A Taylor Swift-inspired task management application designed to showcase fundamental and intermediate frontend development concepts. This project transitions from basic data binding to a fully functional, interactive "Tay-Do" list.

### 📝 Project Description

This repository contains two levels of web application complexity. The **Basic Level** demonstrates core concepts like event handling and conditional rendering, while the **Intermediate Level** features a fully functional "Tay-Do" task manager with persistent state logic.

---

### ✨ Features

* **Data Display & Binding:** Real-time synchronization between input fields and text displays ("It's me, Hi!").
* **Event Handling:** Interactive buttons to change application state and text.
* **Conditionals:** Dynamic UI elements that toggle visibility based on logic.
* **Task Management:** Add, complete (strike-through), and delete tasks.
* **List Rendering:** Dynamic generation of tracklists and task items.
* **Progress Tracking:** Automatic counter for pending tasks.

### 🛠️ Installation & Setup

To run this project locally, follow these steps:

1. **Clone the repository:**
```bash
git clone https://github.com/AnaMariaVoineag/Tay-Do.git
```

2. **Navigate to the project folder:**
```bash
taydo-list-vue
```

3. **Install dependencies by running the following comand:**
```bash
npm install
```
4. **Launch the Development Server using the following command:**
```bash
npm run dev
```
